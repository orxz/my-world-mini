## ▶️ 快速开始

**方式一(最简单):** 直接双击 `index.html`(推荐 Chrome / Edge)。

**方式二(本地服务器,推荐用于开发):**

```bash
npm install      # 仅装开发依赖(ESLint),游戏运行时不需要
npm run serve    # python3 -m http.server 8843
# 浏览器访问 http://localhost:8843/
```

> 游戏本身**零构建**:`index.html` 直接 `<script src>` 引入 `worldgen.js` / `craft.js` / `three.min.js` / `audio.js` / `save.js` / `doors.js` / `game.js`。
> `npm` 只用于跑测试和 lint(见 [开发](#-开发))。

## ✨ 核心系统

### 🌍 近似无限世界(动态区块加载)
- 世界分为 **16×16 区块(chunk)**,玩家走动时自动加载前方区块、卸载后方区块
- 渲染半径 `RENDER_DISTANCE=5`(默认加载 11×11 = 121 个区块),世界高度 48 格,海平面 14
- 确定性噪声生成(同种子同坐标永远一致),存档只需存种子 + 玩家改动 diff
- **面剔除 + 纹理图集 + 贪心网格合并**:每区块按面方向做切片贪心合并(同面同材质的连续面合并为大四边形),三角形数比逐块面降 ~70%;合并后贴图经 shader `fract` 平铺逐块重复,每区块合并为至多 3 个 BufferGeometry(实体/树叶/水),1–3 draw call
- **顶点色烘焙**:顶面亮/侧面中/底面暗,固定立体感不依赖光照方向

### 🏞️ 6 种生物群系
| 群系 | 特征 |
|---|---|
| 平原 | 草地,稀疏树木 |
| 森林 | 草地,密集树木 |
| 沙漠 | 沙地,无树 |
| 山地 | 高耸崎岖裸岩(平滑过渡,无断层) |
| 雪原 | 雪覆盖,云杉 |
| 海洋 | 清水蓝水域(海平面以下),沙岸 |

- 群系由温度 + 湿度 + 山地三层噪声决定,自然过渡
- 水为纯清水蓝(`MeshBasicMaterial`),半透明可游泳,水中减速 + 蓝雾 + 浮力
- **洞穴生成(R24)**:地下 3D 噪声挖出蜿蜒隧道与深处空腔(确定性,占地下约 1.5%);
  陆地保留地表 2 格壳(不塌顶)、海底保留 3 格壳(水不漏进洞)、出生广场
  |x|,|z|≤30 地下完整;**洞内天然黑暗**(天光遮蔽按深度衰减)——火把探洞闭环

### 🚃 矿车与铁轨(R26)
- **铁轨方块**(6 铁锭 + 1 木棍 → 16 节,经典配方):非固体贴地铺设,需固体支撑
- **矿车**(5 铁锭 U 形 → 1 辆):手持矿车对铁轨(或其下方地面)右键放置
- **轨道行驶**:沿铁轨寻路(优先直行、弯道自动转弯、死头弹回震荡至停);
  惯性物理(推动后按摩擦衰减);**乘坐**:右键矿车上车,自动行驶 4.5 格/秒,
  空格下车(带惯性);**左键击打**:移动中=顺向助推,静止=回收掉落矿车物品
- 轨道被拆 → 矿车出轨坠落落地;矿车随存档持久化(minecartsData)

### ⭐ 经验与附魔(R28)
- **经验系统**:击杀生物掉落经验球(敌对 5/末影人 10/被动 1-3 点,散落小绿晶),
  4.5 格内磁吸飞向玩家吸收;经验条 HUD(热栏上方绿条 + 等级数字);
  升级阈值随等级递增(8+4×级);死亡损失一半经验(经典简化);随存档持久化
- **附魔台**(2 钻石+3 书+1 石头):右键打开,手持工具/武器/弓/护甲从 3 个随机
  选项中挑选(等级 I-III = 消耗 1-3 级经验)
- **附魔效果**:**锋利**(近战 +1 伤害/级)· **效率**(挖掘速度 ×(1+0.45×级))·
  **保护**(护甲点 +1/级)· **耐久**(损耗概率 ÷(1+级))· **力量**(箭矢 +1/级)
- 附魔随物品存档(hotbar/armor 携带 ench 字段)

### 🎣 钓鱼 · 繁殖 · 面包(R29)
- **钓鱼**:钓鱼竿(3 木棍+2 蛛丝经典配方)—— 对水面右键甩竿,浮标落水;
  2~5 秒后咬钩(浮标下坠抖动 + 提示),**窗口内再右键收鱼**:生鱼 70% /
  蛛丝 15% / 皮革 10% / 绿宝石 5%;超时鱼会跑;生鱼可熔炉烤成烤鱼
- **动物繁殖**:手持小麦右键牛/羊/猪喂食进入求爱模式(头顶红心),
  两只同类靠近即产崽(幼崽 0.55 缩放,60 秒长大);生育冷却 60 秒;
  幼崽随存档持久化(mobsData.baby)
- **面包**:3 小麦一排 → 1 个面包(+5 饥饿);成熟麦田(叶子状态 + 保留的
  种植标记)破坏时额外掉落小麦

### 🏠 村庄小屋(R31)
- 平原/森林随机生成**经典小屋**(每 48 格村格约 50% 概率,确定性随种子):
  木板墙体 + 原木屋顶 + 地板/地基、2 格高门洞、三面玻璃窗、屋内**火把**
  (接入逐方块光照,屋内光级 14)、角落**箱子**(右键打开,惰性空内容)、
  门前 3×2 **农田**(泥土 + 水渠)
- 生成侧结构,**零存档 diff 成本**(不进 modifications);出生广场保护区
  (中心 ±40)不生成;小屋附近不种树(树冠不堵门);同种子永远一致

### 🧑‍🌾 村民与交易(R33)
- 每座小屋常驻 **≤2 名村民**(棕袍大鼻模型,双臂交叠经典站姿):
  平时村边慢逛,离村 >14 格自动回家;被攻击不还手、转身逃跑(经典)
- **右键村民开交易面板**(7 行经典绿宝石经济):
  卖出 = 小麦×18 / 煤×15 / 生鱼×6 / 皮革×8 → 绿宝石;
  买入 = 绿宝石×1 → 面包×4、绿宝石×2 → 箭×12 / 熟猪排×5
  支付不足的行自动置灰;快捷栏满时产物掉落脚边不亏;`Esc`/`E` 关闭
- 交易表与计数/消耗/判定在 `inventory.js` 纯函数层(单测覆盖);
  村民随 `mobsData` 入存档,读档自动重算所属小屋

### 🏆 成就系统(R34)
- **16 条经典里程碑**自动检测:获得木头/工作台/石器时代/热熔炉/铁器时代/
  钻石!(拾取与合成链)、怪物猎人/拆弹专家(击杀)、渔夫、烤面包、
  牧场主(繁殖)、甜美的梦(睡觉)、矿工之旅(乘矿车)、附魔师、
  交易大师、发现村庄(靠近小屋 24 格自动触发)
- **金色 toast** 右上角滑入「进度已达成!」(经典样式);
  **暂停菜单 → 🏆 成就** 查看全清单(未解锁灰显 🔒)+ 进度计数;
  成就随存档持久化(`achvData`),换档不串;定义与解锁判定在
  `machines.js` 纯函数层(单测覆盖)

### 🟢 史莱姆 · 剪刀 · 黏液块(R35)
- **史莱姆**(经典蹦跳怪):地面蓄力 → 跳跃逼近,接触伤害按体型
  (大 4 / 中 2 / 小 0);**死亡分裂** —— 大→2-3 只中、中→2-3 只小,
  最小级掉黏液球;夜间生成池 5%;体型与血量随 `mobsData` 入存档
- **剪刀**(2 铁锭对角经典配方,耐久 238):手持对羊右键剪毛
  (掉 1-3 白羊毛、羊换粉皮、45 秒长回);剪过的羊击杀不再掉羊毛
- **黏液块**(4 黏液球经典配方):新方块(胶质贴图),玩家重着陆
  **弹起**(越猛越高,7-14)+ 免摔伤 —— 经典蹦床;成就「黏糊糊」(击碎小史莱姆)

### 🪣 铁桶与水(R36)
- **铁桶**(3 铁锭 V 形经典配方):空桶对水右键 **舀水**(水格被装走变空气,
  桶变水桶;遇墙/树叶等固体视线即停);水桶对方块右键 **倒水**
  (相邻格生成真实 water 方块,桶变空桶)
- **可移动水源**:倒出的水可游泳(浮力/水下判定)、可再舀取(桶↔水桶
  无限往返);静态不扩散;水方块变化随 modifications 入存档
- 桶/水桶有 2D 图标与 3D 手持模型;成就「桶装玩意」(装一次水);
  支付目标格被占(如已有水)时拒绝倒水不消耗

### 🏰 地牢(R37)
- **确定性生成侧结构**(零存档 diff):每 64 格地牢格 ~35% 概率一座地下石室
  (7×7×5:圆石地板/砖石顶/参差砖墙),埋深 ≥2 且避开出生广场;同种子永远一致
- **刷怪笼**(新方块,中央):玩家 12 格内每 2 秒在笼旁空位生成对应怪
  (僵尸 40%/骷髅 35%/蜘蛛 25%,每笼同类 ≤3);16 格内笼芯冒火粒;
  挖掉即失效;破坏无掉落(经典)
- **战利品箱**(1-2 个角箱):首次打开按「世界坐标+种子」确定性 hash
  填充 3-5 件经典战利品(铁/金/钻石/绿宝石/面包/箭/丝线/铁桶加权),
  重开不重复、删缓存重开同内容;打开解锁成就「宝箱猎人」
- 结构函数在 worldgen.js 纯函数层(单测);战利品 roll 在 inventory.js

### ⚡ 红石基础(R38)
- **红石矿**(深层 y<14 生成)→ 挖掘掉 4-5 **红石粉**;地牢战利品也出红石粉
- **三种经典配方**:红石火把(1 粉+1 木棍)/ 拉杆(1 木棍+1 圆石,默认关)/
  红石线(1 粉直接铺设)
- **信号网络**(经典):电源 = 红石火把(常开 15)/ 拉杆(开态 15);
  红石线 BFS 传播每格 **-1 衰减**,多源取最大;每 0.25s 重算
  (算法在 machines.js 纯函数 `redstonePower`,单测覆盖)
- **执行器 = 铁门**:任一门格相邻充能 >0 → 自动开,断能自动关;
  铁门手动右键被拒绝(经典,需红石驱动)
- **交互**:拉杆右键切换开/关(双 id 方块,状态随存档);元件一击可拆
  (非固体走视线采样);拆支撑弹出元件;读档后信号网络自动重建;
  成就「电路初成」(放置红石火把)

### 👨‍👩‍👦 村民繁殖 · 铁傀儡(R39)
- **村民繁殖(经典吃面包)**:手持面包右键村民喂食(幼崽/生育冷却/
  已求爱拒绝;村内 24 格 ≥6 人时「人满为患」),两只求爱村民会合产
  **村民幼崽**(0.55 缩放,60 秒长大,自动绑定村庄 home);
  幼崽右键只想玩耍不开交易
- **铁块**(新方块,9 铁锭压缩/1 块分解 9 锭经典配方)
- **铁傀儡(构造生成)**:铁块搭 T 形(竖 4 柱=身体 3+头,侧放 1 臂
  收尾;或臂已就位放头)→ 结构消失、原地苏醒铁傀儡(hp100)

## 🧱 技术栈
- Three.js r160(WebGL 渲染)、原生 JavaScript(无框架、无构建)
- Canvas 2D(程序化纹理图集与图标)
- Web Audio API(程序化音效合成)
- IndexedDB(多存档,DB v2)

## ⚙️ 关键实现
- **区块网格构建**:遍历每个方块 6 面,只生成暴露在空气/水外的面,按方块类型从纹理图集取 UV,合并为实体/树叶/水三套 BufferGeometry + 顶点色烘焙(实体与树叶均在不透明队列,水半透明)
- **raycast(DDA 体素步进)**:从眼睛沿视线逐体素步进(约 6 个体素),首块固体即命中;法线由进入面反推,结果对象与向量全池化(每帧零 GC 分配)
- **存档 diff**:只存玩家改动过的方块 `{x,y,z} -> type|null`,加载时在确定性生成的基础上覆盖应用
- **多存档**:IndexedDB 自增 id,每个存档独立(seed + modifications + 玩家状态),可任意创建/读取/删除
- **确定性广场**:出生广场用 modifications 记录(仅存与自然地形的差量,存档小、保存快),每次生成一致,新游戏/重置都重建
