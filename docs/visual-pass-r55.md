# R55 视觉与体验优化记录

> 日期：2026-10-18｜版本：v2.5.0｜范围：画面正确性、出生场景、开始屏、HUD、反馈
> 验证：`npm test` 160/160、ESLint 0/0、smoke / r44 / r45 / r47 / r48 / r51 / r52 / r55 全绿

## 一、最重要的修复：图集 UV 上下颠倒

**现象**：草地、"石头"地面看起来是棕色泥土;草方块顶面永远不是绿色,整个世界偏灰棕。

**根因**：`CanvasTexture` 默认 `flipY=true`,UV 的 v=0 对应画布底部。`buildAtlas` 把行序
top(0-15)/side(16-31)/bottom(32-47) 映射成了 `top=v0..1/3`、`bottom=v2/3..1` ——
**顶面采样到了 bottom 贴图,底面采样到了 top 贴图**。

**修复**（`game-atlas.js`）：

```js
top:    [u0, 1,   u1, 2/3],
side:   [u0, 2/3, u1, 1/3],
bottom: [u0, 1/3, u1, 0],
```

**效果**：草方块顶面恢复绿色,石头/木板/沙子/树叶的顶面与底面各自正确;这是本轮
观感提升最大的一项,且零性能成本。

## 二、出生场景：从"石壳里的黑屏"到开阔广场

### 2.1 山地不再盖住出生点
- **问题**：出生广场只写到 `platH=20`,山地地形可到 44;中心 `y22+` 仍是天然石头,
  玩家出生在 1 格高的石壳里,画面几乎全黑。
- **修复**：`generateChunkData` 对 `|x|,|z| ≤ 28` 的范围把地形高度钳到广场高度;
  `growTreesInChunk` 在广场内不种自然树。生成侧处理,零存档 diff;旧档重载同样生效。

### 2.2 出生视角
- Owen 字样整体北移 12 格,喷泉石柱从 4 格高降为 2 格石座 + 1 格水花;
  出生点仍在广场中心,但面前是开阔草地/树篱/拱门,不再被字母和石柱贴脸。
- 开局木镐从第 9 格移到**第 1 格并选中**——新玩家手里直接有工具。

## 三、开始屏与 HUD

- **开始屏**：标题/按钮字号随视口收缩;操作说明改为**两列网格**(移动端单列);
  内容超屏时可滚动;点击说明区不再误触开局。
- **面板压暗**：打开背包/合成台/熔炉/箱子/交易/配方/统计/成就/暂停时,
  世界统一压暗 50%,面板成为视觉焦点(MutationObserver 监听面板状态,零每帧开销)。
- **暗角**：全屏轻暗角(中心透明 → 边缘 26% 黑),让画面更聚焦,不遮挡 HUD。
- **准星状态**：对准可右键交互目标时变**绿色**;工具层级不足时变**橙红色**;
  方块选中框同步:可收获=黑色细框,层级不足=橙红粗框。
- **信息面板**：字号/内边距收紧;`F3` 一键显示/隐藏。
- **操作说明**：补上 `F3 信息`、配方书 `J`、目标 `H`。

## 四、反馈与手感

- **受击/爆炸镜头震动**：0.22s / 0.35s,正弦位移,幅度随伤害;设置"减少动态"时禁用。
- **死亡遮罩**：显示死因(近战/爆炸/摔落/溺水/饥饿)与掉落物坐标。
- **材质脚步音**：草/土闷、石脆、木中、沙/雪沙沙(Web Audio 噪声频率区分)。
- **命中标记**：普通白 X / 暴击金 X(此前已有,保留)。
- **启动工具**：开局选中木镐,准星提示立即显示"左键挖掘"语义。

## 四、UX 打磨(本轮追加)

- **暂停菜单两列分组**:游戏/存档/世界与设置/危险操作分区,卡宽 720,16 个入口一屏可见(此前需滚动且底部被截)。
- **背包搜索**:图鉴上方搜索框,按名称/id 实时过滤;搜索时隐藏护甲槽与分组标题,清空恢复。
- **点击面板外关闭**:压暗层可点击,关闭配方书/统计/背包/合成台/熔炉/箱子/交易/附魔;暂停菜单除外,避免误退出。
- **重置世界二次确认**:`confirm` 提示会丢失未保存进度,防误触。
- **合成满栏提示**:产物因快捷栏满而掉地时,toast 明确提示「快捷栏已满,余量掉在脚下」。
- **F3 只显示调试信息**:信息面板默认只保留坐标/群系/时间;已加载区块与 FPS 由 F3 展开,减少新手 HUD 噪音。
- **关面板误暂停修复**:请求指针锁失败后的 600ms 内不弹暂停菜单。
- **开始屏说明区不误触**:点击/触摸操作说明不会开局,移动端可安全滚动阅读。
