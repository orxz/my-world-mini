## ▶️ 快速开始

**方式一(最简单):** 直接双击 `index.html`(推荐 Chrome / Edge)。

**方式二(本地服务器,推荐用于开发):**

```bash
npm install      # 仅装开发依赖(ESLint),游戏运行时不需要
npm run serve    # python3 -m http.server 8843
# 浏览器访问 http://localhost:8843/
```

> 游戏本身**零构建**:`index.html` 直接 `<script src>` 引入 `worldgen.js` / `craft.js` / `three.min.js` / `game.js`。
> `npm` 只用于跑测试和 lint(见 [开发](#-开发))。

## ✨ 核心系统

### 🌍 近似无限世界(动态区块加载)
- 世界分为 **16×16 区块(chunk)**,玩家走动时自动加载前方区块、卸载后方区块
- 渲染半径 `RENDER_DISTANCE=5`(默认加载 11×11 = 121 个区块),世界高度 48 格,海平面 14
- 确定性噪声生成(同种子同坐标永远一致),存档只需存种子 + 玩家改动 diff
- **面剔除 + 纹理图集 + 几何合并**:每区块合并为至多 3 个 BufferGeometry(实体/树叶/水),1–3 draw call
- **顶点色烘焙**:顶面亮/侧面中/底面暗,固定立体感不依赖光照方向

### 🏞️ 6 种生物群系
| 群系 | 特征 |
|---|---|
| 平原 | 草地,稀疏树木 |
| 森林 | 草地,密集树木 |
| 沙漠 | 沙地,无树 |
| 山地 | 高耸崎岖裸岩(平滑过渡,无断层) |
| 雪原 | 雪覆盖,云杉 |
| 海洋 | 清水蓝水域(海平面以下),沙岸 |

- 群系由温度 + 湿度 + 山地三层噪声决定,自然过渡
- 水为纯清水蓝(`MeshBasicMaterial`),半透明可游泳,水中减速 + 蓝雾 + 浮力

### 💾 多存档管理(IndexedDB)
- **多存档**:可保存任意数量的独立存档,每个存档有唯一 id + 名称 + 时间戳
- **存档管理面板**:暂停菜单 → 「📂 存档管理」,列出所有存档(名称/位置/改动数/时间),可读取/删除
- **自动保存**:有当前存档时,30 秒 + 暂停 + 改动防抖 自动覆盖保存
- 只存 **种子 + 玩家改动 diff(modifications)**,不存全量方块,容量小加载快
- 读档完全恢复:世界改动 + 玩家位置/朝向 + 快捷栏 + 视角模式

### 🔊 程序化音效(Web Audio,无外部文件)
- 用 `OscillatorNode` + 白噪声合成,零依赖
- 破坏 / 放置 / 走路 / 跳跃 / 落地 / 入水 等音效
- 暂停菜单:「音效:开/关」开关

### 🏛️ 出生广场(固定场景)
每次进入(新游戏/重置/读档回原点)都生成同一个固定广场:
- **圆形广场**(半径 28)+ 石板/木板环形纹理
- **中央 "Owen" 字样**(树叶,木板底座)
- **四角砖块灯塔**(4 座)
- **环形树篱**(边缘一圈小树)
- **南北入口路径**(木板路延伸 + 拱门)
- **中心喷泉**(水池 + 石柱)
- **蘑菇 / 花坛 / 旗杆 / 小山丘** 装饰
- **6 个俯视像素艺术**(笑脸/爱心/星星,彩色方块)

### 🧱 物品系统(创造模式)
- **20 种方块**:
  - 基础 8 种:草、泥、石、木、叶、沙、木板、砖
  - 环境 3 种:水(可游泳)、雪、沙砾
  - 装饰 4 种:红/黄/白/黑羊毛(纯色,适合像素艺术)
  - 门 5 种:木门、铁门、石门、金门、钻石门(2 格高实体,右键开关、左键移除)
- **24 种工具**(5 档材质:木/石/铁/金/钻石):
  - 镐 / 斧 / 铲(破坏对应类别方块更快,工具头形状各异)
  - 剑(伤害值:钻石 8 > 铁 6 > 石 4 = 金 4 > 木 3)
  - 盾(举盾时抬高到身前)
  - 弓(配箭使用,抛物线飞行 + 重力)
- **6 种材料**(可堆叠 64):钻石、金锭、铁锭、绿宝石、箭、木棍
- 所有工具带耐久度,使用消耗,耗尽自动移除

### 🔨 合成系统(2×2 配方)
- 背包(E)→ 合成区:2×2 合成格 + 结果预览 + 合成按钮
- **35 种配方**(在 `craft.js` 定义,可单测),完整覆盖材料链 → 工具 → 武器 → 门:
  - **材料链**:1 木头→4 木板;2 木板(纵向)→4 木棍;木棍+沙砾→4 箭;
    4 石头→2 石砖;4 沙子→2 沙砾;4 雪→水
  - **工具(20 种)**:五档材质(木/石/铁/金/钻石)× 镐/斧/铲/剑,统一 2×2 图案:
    镐=`[材,材,材,棍]`、斧=`[材,材,棍,∅]`、剑=`[材,材,∅,棍]`、铲=`[材,∅,棍,∅]`
    (木档材质=木板,石档=石头,金属档=对应锭)
  - **弓盾**:3 木棍→弓;4 木板→木盾;木板+铁锭交错→铁盾;木板+钻石交错→钻石盾
  - **门(5 种)**:2 木板(横向)→木门;2 石头(纵向)→石门;2 金锭(横向)→金门;
    4 铁锭→铁门;4 钻石→钻石门
- 无序配方任意摆放即可,有序配方(工具/门)必须精确位置;合成的工具自动带满耐久
- 合成匹配与破坏耗时逻辑在 `craft.js`(纯函数),`matchRecipe`/`breakCost` 有单元测试覆盖

### 🌾 农作物(小麦)
- 手持「雪」,对**草方块**右键 → 种下小麦(雪方块作幼苗)
- 60 秒后自动成熟(雪→成熟小麦,树叶方块呈现)
- 种植时间随存档持久化(绝对时间),退出重进照常成熟

### ❤️ 健康系统(跌落/溺水)
- **20 HP**(10 颗心),HUD 左下角红心显示,随存档保存
- **跌落伤害**:坠落速度过快落地受伤(约 4.3 格自由落体开始掉血,按速度分档),飞行免疫
- **溺水伤害**:头部在水下持续 15 秒后每秒扣 1 HP,浮出水面重置
- 死亡后显示死亡画面,可重生于出生广场(生命回满)

### 🧍 玩家模型(第三人称)
- Minecraft 风格人形(大头短腿宽身),严格匹配 1.8 高碰撞盒,脚踩地不穿墙
- 头部贴图:眉毛/蓝瞳眼睛/鼻子/嘴/腮红/胡茬(确定性像素布局)
- 行走动画(对角摆臂)、待机呼吸、挥剑弧线
- 手持物显示(第一人称屏幕右下 + 第三人称右手),工具头按类型区分

### 📷 三种视角(F5 切换)
- **第一人称**:相机贴眼睛,手持物显示在屏幕右下(空闲浮动动画)
- **第三人称背后**:距离 3.5 米,略俯视,看玩家全身背影
- **第三人称正面**:相机在身前,看玩家脸;WASD 智能翻转
- 相机碰撞检测:背靠墙时自动拉近,不穿模
- **切换人称后模型跟随玩家**(不停留原地)

## 🎨 视觉优化
- **光照**:环境光 0.42 + 半球光 0.25 + 方向光(太阳对齐),方块立体明暗分明
- **ACES 色调映射**:防止高光过曝,画面通透
- **视野设置**:设置面板可调 FOV(65/75/85/100,持久化保存)
- **粒子效果**:破坏方块迸溅彩色碎屑(取方块本色),重力下落 + 缩小淡出;放置方块少量粒子
- **准星**:黑白描边,亮暗背景都清晰可见
- **UI**:toast 上移不挡准星;破坏进度条(不再刷屏)

## 🛡️ 边界处理
- **基岩层**:y=0 不可破坏(防止挖穿掉虚空)
- **虚空救援**:掉入虚空返回最后安全位置(非原点)
- **出生点**:固定在广场中心,海平面以上干燥陆地

## 🛠 开发

需要 **Node.js ≥ 18**(仅用于测试/lint,游戏运行时不需要)。

```bash
npm install      # 安装开发依赖(ESLint 9)
npm test         # 跑确定性函数单元测试(46 项)
npm run lint     # ESLint 静态检查
npm run serve    # 启动本地静态服务器 http://localhost:8843/
```

- **测试**:`test/unit.test.js` 覆盖 `worldgen.js`(哈希/噪声/群系/高度/存档序列化)与
  `craft.js`(配方匹配/破坏耗时)的纯函数
- **浏览器冒烟测试(可选)**:`test/smoke.cdp.mjs` 通过 CDP 驱动 headless Chrome 做 23 项端到端断言
  (触屏物理/门持久化/树木标脏/存档往返等),用法见文件头注释
- **Lint**:`eslint.config.mjs`(flat config);`game.js`/`worldgen.js`/`craft.js` 是经典 script(非 ES module)
- **CI**:GitHub Actions 在 push/PR 自动跑 `npm test` + `npm run lint`
- 详细代码组织、数据流、扩展点见 **[docs/architecture.md](./docs/architecture.md)**
- 世界生成函数 API 参考 **[docs/worldgen.md](./docs/worldgen.md)**

## 🧱 技术栈
- Three.js r160(WebGL 渲染)、原生 JavaScript(无框架、无构建)
- Canvas 2D(程序化纹理图集与图标)
- Web Audio API(程序化音效合成)
- IndexedDB(多存档,DB v2)

## ⚙️ 关键实现
- **区块网格构建**:遍历每个方块 6 面,只生成暴露在空气/水外的面,按方块类型从纹理图集取 UV,合并为实体/树叶/水三套 BufferGeometry + 顶点色烘焙(实体与树叶均在不透明队列,水半透明)
- **raycast(DDA 体素步进)**:从眼睛沿视线逐体素步进(约 6 个体素),首块固体即命中;法线由进入面反推,结果对象与向量全池化(每帧零 GC 分配)
- **存档 diff**:只存玩家改动过的方块 `{x,y,z} -> type|null`,加载时在确定性生成的基础上覆盖应用
- **多存档**:IndexedDB 自增 id,每个存档独立(seed + modifications + 玩家状态),可任意创建/读取/删除
- **确定性广场**:出生广场用 modifications 记录(仅存与自然地形的差量,存档小、保存快),每次生成一致,新游戏/重置都重建
