## 四、不破坏开场节奏

1. **教程/目标零改动**：出生点、第一棵树、合成台、圆石目标位置均不变。
2. **新内容全部在半径 23 之外**：前 60 秒的「砍树→合成→挖石」动线不受阻挡。
3. **外环是可选支线**：不去也能正常生存；想去时四门与主轴步道给出明确方向。
4. **地形连续**：38–46 平坦草甸 + 四门坡道，避免「出门撞墙」破坏第一印象。
5. **视觉先给锚点**：入口拱门、灯柱、彩色花点把视线引向远处，而不是把内容堆在出生点。

## 五、视觉与氛围

- **地形**：内环石径 28 → 外环木道 30/31 → 草甸 38–46，形成「广场-环路-草甸」三层尺度。
- **装饰**：四门彩球/火把、主轴灯柱+花点、外环彩色花点、野餐桌/篝火、码头围栏。
- **光照**：四门火把、多组主轴/环路火把、瞭望塔顶火把、迷宫中心火把；夜间可读。
- **色彩**：红/黄/白羊毛集中在门与设施，草地/树篱保持大面积绿色，避免视觉噪音。
- **氛围**：白天开阔草甸 + 远处树线；夜晚火把串成路径，适合儿童辨认方向。

## 六、实现

- `PLAZA_RADIUS` 28→**46**：worldgen 只负责平坦草甸与不种自然树；
  `buildSpawnPlaza` 的 `plazaR` 28→**38** 负责实际铺地/树篱/灯塔/像素画。
- `buildOuterSpawn(set, fill, platH, plazaR)`：外环道路、四门、五个探索点、
  灯柱/花点、导览牌；全部走 `set()` 写 modifications，不触发实体副作用。
- `spawnPOIs` + `getNearbySpawnPOI()`：HUD 在探索点 4–9 格内显示导览；
  不弹窗、不打断移动。
- 出生点/重生点保持 (0.5, 21.9, 0.5)；教程与游乐设施坐标不变。
- 旧档：`plazaBuilt=true` 的新档读档会重建外环；旧档保持原广场 diff，不强制迁移。
