# R55 UX 评审与修复记录

> 日期：2026-10-18｜范围：暂停菜单、背包、面板层级、开始屏、提示反馈
> 方法：截图审查 + DOM/层叠检查 + 20 套 CDP 回归

## 一、结论

本轮发现 **2 个高优先级交互缺陷、3 个中优先级问题、3 个低优先级文案/布局问题**，
已全部修复。核心是：暂停菜单一屏放不下、压暗层把 toast 和快捷栏一起挡掉。

## 二、问题与修复

### High

**H1 暂停菜单 16 个入口一屏放不下**
- 现象：1280×720 下 `pause-card` 内容高 1000px、可视 628px，底部的重置/操作说明被截，
  必须滚动才能看到。
- 修复：两列分组（存档 / 游戏 / 世界与设置 / 危险操作），卡宽 720，按钮紧凑化；
  实测内容高 563px，一屏完整显示。
- 移动端 `max-width:640` 回落单列 + 卡片内滚动。

**H2 面板压暗层把 toast 挡住**
- 现象：合成/提示 toast 的 `z-index:15`，新压暗层 `z-index:78`；开背包合成立即看不到
  「合成成功 / 快捷栏已满」等反馈。
- 修复：`#toast` 提到 `z-index:99`（高于面板、低于开始遮罩）。

### Medium

**M1 快捷栏被压暗层挡住**
- 现象：压暗层 `pointer-events:auto` 后，开背包时底部快捷栏可见但点不到。
- 修复：`#hotbar` 提到 `z-index:79`（高于压暗层，低于面板），并保留 `opacity:.6` 的
  弱化；开背包仍可切槽。

**M2 搜索框内按 Esc 不关面板**
- 原因：全局 keydown 对 `INPUT` 直接 return，Esc 被吞。
- 修复：背包搜索、配方搜索各自加 `keydown`：Esc 关闭当前面板；其余按键正常输入。

**M3 搜索无结果时没有空态**
- 修复：`#inv-empty`「没有匹配的物品」；有结果或清空查询时自动隐藏。

### Low

- 开始屏 `继续上次游戏` 被 `.menu-btn { width:100% }` 拉成整行 → `#overlay #btn-continue`
  改为 `width:auto; min-width:320px`。
- 开始屏 F3 文案仍写「信息」，实际只展开调试信息 → 改为「调试 F3」。
- 暂停菜单操作说明仍写「成就 23 项」→ 改为 29 项；按钮初始占位同步。

## 三、保留的设计决策

- **点击压暗层关闭面板**：配方/统计/背包/合成台/熔炉/箱子/交易/附魔；**暂停菜单不关**，
  避免误点空白直接回游戏。
- **F3 默认只显示坐标/群系/时间**：区块数/FPS 属调试信息，默认隐藏减少新手 HUD 噪音。
- **关面板指针锁失败 600ms 内不暂停**：避免「关背包突然弹暂停」；代价是关面板后立刻按
  Esc 的 600ms 内不弹暂停，可接受。
- **重置世界二次确认**：原实现单击即重置，属于高风险误触。

## 五、剩余风险 / 后续建议

- **原生 `confirm`** 无法自动化测试；后续可换自定义确认弹窗，统一视觉。
- **MutationObserver 监听 body childList**：当前只有 toast/成就追加，开销可忽略；若后续
  高频动态节点增多，建议改为面板注册表 + 显式 `syncPanelDim()`。
- **没有加载进度**：进入游戏仍可能看到区块逐帧出现；下一步可加 0.5–1s 的生成进度遮罩。
- **移动端 HUD 仍偏满**：顶部信息 + 目标卡占约 200px；可考虑目标卡折叠为单行。
- **新增面板必须加入 `PANEL_IDS`**，否则不会触发压暗；已在 `game-ui.js` 注释中标注。
